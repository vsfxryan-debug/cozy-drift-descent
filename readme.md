# Cozy Drift Descent

A browser-based drift-surf racing game with roguelite upgrades.
Drift, surf steep banks, and build a flow multiplier down five cozy mountains.

## Play
Just open `index.html` via a static server (or push to GitHub Pages).

## Local dev
Because it uses ES modules + import maps, you need a static server:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
